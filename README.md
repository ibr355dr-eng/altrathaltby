# تراث الطب العربي

موقع أرشيفي شخصي يجمع المراجع والبحوث والملاحظات في تاريخ الطب عند العرب والمسلمين،
ويعرضها على شكل بطاقات تُفتح في نوافذ داخلية أو روابط خارجية.

- موقع ثابت بالكامل (HTML + CSS + JavaScript) — بلا أي اعتماديات ولا عمليات بناء.
- يعمل على الحاسب والجوّال واللوح، ويدعم الوضع الليلي والاتجاه من اليمين إلى اليسار.
- بحث فوري يتجاوز فروق الهمزات والتشكيل، وتصفية بالتصنيف والنوع، وترتيب متعدد.

---

## كيف أضيف رابطاً أو بحثاً؟

كل المحتوى في ملف واحد: **`data/resources.js`**

افتح الملف، وانسخ هذا القالب، وضعه قبل السطر الأخير `];` — مع فاصلة `,` بعد الكتلة السابقة:

```js
  {
    title: "عنوان المصدر",
    url: "https://example.com/page",
    type: "بحث",
    category: "دراسات حديثة",
    desc: "وصف مختصر للمصدر في سطرين أو ثلاثة.",
    tags: ["ابن سينا", "صيدلة"],
    note: "ملاحظتي الخاصة على هذا المصدر.",
    added: "2026-10-13",
    featured: true
  },
```

### الحقول

| الحقل | إلزامي | الوصف |
|---|---|---|
| `title` | نعم | عنوان المصدر كما يظهر في البطاقة |
| `url` | نعم (إلا في الملاحظات) | الرابط الخارجي |
| `type` | نعم | النوع — يظهر في قائمة «النوع» تلقائياً |
| `category` | نعم | التصنيف — يظهر كزر تصفية تلقائياً |
| `desc` | مستحسن | وصف مختصر (يُقتطع بعد ثلاثة أسطر) |
| `tags` | لا | وسوم؛ الضغط على الوسم يبحث عنه |
| `note` | لا | ملاحظتك الشخصية، تظهر بإطار ذهبي |
| `added` | لا | `YYYY-MM-DD` — يُستخدم في ترتيب «الأحدث إضافة» |
| `featured` | لا | `true` لتمييز المصدر ووضعه في المقدمة |

### الأنواع الجاهزة (لها أيقونات)

`مخطوط` · `مكتبة` · `بحث` · `مقال` · `كتاب` · `ملاحظة` · `موسوعة` · `مرئي` · `أرشيف`

> يمكنك كتابة أي نوع آخر، وسيعمل كل شيء — لكن ستظهر له أيقونة افتراضية.
> التصنيفات (`category`) حرّة تماماً: اكتب ما تشاء وسيُبنى زر التصفية وحده.

### ملاحظة شخصية بلا رابط خارجي

احذف `url`، واجعل النوع `ملاحظة`، واكتب النص في `body`
(استخدم `\n` للفصل بين الفقرات):

```js
  {
    title: "خلاصة قراءة في كتاب الحاوي",
    type: "ملاحظة",
    category: "ملاحظاتي",
    desc: "عنوان فرعي يظهر أعلى النص",
    body: "الفقرة الأولى.\nالفقرة الثانية.",
    added: "2026-10-13"
  },
```

## أمور مهمة

- **اقتباسات مزدوجة:** إن كان في النص علامة `"` فاكتبها `\"` أو استخدم `«»`.
- **الفواصل:** لا بد من فاصلة `,` بين كل كتلتين، ولا فاصلة بعد الكتلة الأخيرة.
- **الروابط:** اكتبها كاملة مع `https://`.
- **النوافذ الداخلية:** بعض المواقع (أغلب المجلات العلمية والمكتبات) تمنع العرض
  داخل الإطارات لأسباب أمنية. في هذه الحالة يظهر تنبيه داخل النافذة مع زر
  «تبويب جديد» — وهذا سلوك المواقع نفسها لا الموقع.

## معاينة محلية

```bash
cd turath-al-tibb
python3 -m http.server 8080
# ثم افتح: http://localhost:8080
```

## النشر

الموقع منشور عبر **GitHub Pages** من الفرع `main`.
أي تعديل تدفعه (`git push`) يظهر على الموقع بعد دقيقة إلى دقيقتين.

## اختصارات لوحة المفاتيح

| المفتاح | الوظيفة |
|---|---|
| `/` | الانتقال إلى مربع البحث |
| `Esc` | إغلاق النافذة |
