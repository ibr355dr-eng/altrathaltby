# التراث الطبي — altrathaltby.com

## إضافة بحث أو تصنيف (بلا برمجة)

1. ادخل https://app.pagescms.org وسجّل الدخول بحساب GitHub.
2. اختر المستودع `altrathaltby`.
3. **البحوث** ← «إضافة»: العنوان، والرابط بالإنجليزية، والتصنيف، والنبذة، والتاريخ، ثم النص (أو ارفع ملف HTML/PDF جاهزاً) ← حفظ.
4. **التصنيفات** ← «إضافة»: الاسم، والرابط بالإنجليزية، والوصف، والترتيب.
5. **إعدادات الموقع ووسائل التواصل**: رقم واتساب، والحسابات، ونص «عن الموقع».

بعد الحفظ يُبنى الموقع ويُنشر وحده خلال دقيقة تقريباً (GitHub Actions).

- **البحث المدفوع:** اختر «مدفوع» وضع رابط الدفع. يُعرض مجاناً ما قبل سطر فيه `[[المزيد]]`، أو أول ثلاث فقرات.
- **المسودة:** فعّل «مسودة» فلا يُنشر.

## البنية

| المسار | المحتوى |
|---|---|
| `content/settings.json` | اسم الموقع ووصفه ووسائل التواصل |
| `content/categories/*.md` | التصنيفات |
| `content/research/*.md` | البحوث |
| `media/` | الصور والملفات المرفوعة |
| `site/mizaj/questions.json` | أسئلة اختبار المزاج ونقاطها |
| `site/static/` | التنسيق والأيقونات (`tools/make_icons.py`) |
| `.pages.yml` | نماذج محرر Pages CMS |

## معاينة محلية

```bash
pip install markdown pyyaml
python3 build.py && cd docs && python3 -m http.server 8080
```
